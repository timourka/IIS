# ЛР №5 – перенос кубика в Webots

Откройте `webots/worlds/pick_place.wbt` в Webots R2025a и запустите симуляцию. Красный куб лежит слева, зелёная метка справа. Перенос начинается автоматически. Используется простой манипулятор с тремя линейными осями и присоской.

Из папки `lab5`, в Windows:

```text
python run_webots.py --gui
python run_webots.py
python run_webots.py --shifted
python -m unittest discover -s tests -v
```

Если Webots установлен не в `C:\Program Files\Webots`, укажите его папку через `WEBOTS_HOME`. Нужно, чтобы Webots мог запускать контроллеры Python. Дополнительные пакеты Python не нужны. Запуски без `--gui` завершаются автоматически, пишут результаты и кадры в `results/baseline` и `results/shifted` и возвращают ненулевой код при неудаче.

`picker` получает BGRA-кадры и положения осей через Webots Controller API. Порог по цвету выделяет куб и цель в двух ракурсах. Координаты вычисляются проекцией на известные горизонтальные плоскости; координаты куба и цели из сцены в алгоритм не передаются. `verifier` отдельно читает истинные координаты и проверяет результат с допуском 20 мм.

`industrial-robot-sim` – локальная копия исходного репозитория (ревизия `5297b03`), взята для справки по Webots. Новая сцена работает сама: не нужен запуск Industrial Studio, Blockly или судейского модуля. Исходный репозиторий не меняется.

Ограничения прототипа: фиксированные цвета и высота куба, известная калибровка, наблюдение сверху и идеализированная присоска. Нет отдельного UI, нейросетевой сегментации или реконструкции произвольной 3D-формы.
